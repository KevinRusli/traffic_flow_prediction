# Data

`raw/` - files from Canvas, never edit them:

| File | What it is |
|---|---|
| `Scats Data October 2006.xls` | **Main dataset.** Sheet `Data`: 40 SCATS sites, 139 approach locations, 15-min counts V00-V95, 1-31 Oct 2006 |
| `SCATSSiteListingSpreadsheet_VicRoads.xls` | Site numbers -> intersection descriptions (useful for node names) |
| `Traffic_Count_Locations_with_LONG_LAT.csv` | Victoria-wide traffic count locations with coordinates (backup for missing lat/lon, Research) |

`processed/` - generated by `src/data/loader.py` (git-ignored). Delete it to force a rebuild.

Quirks and gotchas: see `docs/DATA_NOTES.md`.
